# Synthetic demo

These files are authored for testing and onboarding. They are not a real research project, an existing paper, a conference template, or evidence of experimental performance.

- `inputs/idea.md`: an example idea for an editable document-triage workflow.
- `inputs/experimental_log.md`: an explicitly incomplete experiment plan; no completed measurements.
- `template/template.tex` and `paperstudio_demo.sty`: a minimal article template with a local style dependency, used to test ZIP import and PDF preview. Supply your own complete conference template for an actual manuscript.

Do not report the demo as a scientific evaluation or replace real experimental evidence with it.
