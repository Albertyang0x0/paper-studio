# Local visual references

The original workspace contains user-supplied paper figures whose redistribution permission is not established. Those images are deliberately absent from the GitHub source bundle and ignored by Git.

The app lists bundled references only when their PNG files exist. With an empty reference directory it still starts, and users may upload their own authorized reference images in the figure editor. Reference images are visual guidance, not scientific evidence.

Do not commit third-party paper figures, private manuscript artwork, or embedded credentials without the appropriate permission and review.
